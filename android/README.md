# TextBee Android builds

This fork produces separate development and production applications:

- Development: `com.bobpappas.textbee.dev`
- Production: `com.bobpappas.textbee`

The Java namespace remains `com.vernu.sms`; it is independent of the installed
application ID.

## Development APK

Prerequisites:

- JDK 11
- Android SDK platform 34
- ADB for installing and inspecting the APK
- A Firebase Android app in project `textbee-dev-2852f`, registered with the
  package name `com.bobpappas.textbee.dev`

Download that Firebase app's `google-services.json` and save it as:

```text
app/src/dev/google-services.json
```

The file is ignored by Git. It is an Android client configuration file, not the
Firebase service-account JSON used by the API. Never copy a service-account
private key into this project.

Build from this `android` directory with the Mac's private LAN address:

```sh
TEXTBEE_DEV_API_BASE_URL=http://MAC_LAN_IP:8080/api/v1/ \
  ./gradlew assembleDevDebug
```

The URL is required, must be a valid HTTP(S) URL, and must end in `/api/v1/`.
The build fails instead of falling back to an upstream TextBee service.
Cleartext HTTP is enabled only for the development flavor. The development
release variant is disabled so development artifacts always use Android debug
signing.

The resulting APK is:

```text
app/build/outputs/apk/dev/debug/app-dev-debug.apk
```

After verifying that the phone can reach the development Caddy endpoint on the
trusted LAN, install or update it with:

```sh
adb install -r app/build/outputs/apk/dev/debug/app-dev-debug.apk
```

Grant the required SMS and phone permissions on the device, then register it
with an API key generated by the self-hosted dashboard. Registration and
heartbeat testing do not authorize sending a real SMS.

The app derives its dashboard link from the same self-hosted API origin. Its
update action does not open the incompatible upstream APK download; compatible
updates are supplied by the administrator.

## Production APK contract

The production flavor uses:

```text
https://textbee.bobpappas.com/api/v1/
```

It rejects cleartext traffic. Its Firebase Android configuration belongs at
`app/src/prod/google-services.json` and must identify
`com.bobpappas.textbee`.

A production release will not build unless all four external signing values
are supplied:

```text
TEXTBEE_RELEASE_STORE_FILE
TEXTBEE_RELEASE_STORE_PASSWORD
TEXTBEE_RELEASE_KEY_ALIAS
TEXTBEE_RELEASE_KEY_PASSWORD
```

The keystore and credentials must remain outside Git. B010 does not authorize
creating production Firebase credentials, generating a signing key, building
or publishing a production APK, or changing production infrastructure.
